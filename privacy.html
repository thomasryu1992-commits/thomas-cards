개인정보처리방침

시행일: 2026년 10월 28일 · 앱: thomas-shorts

1. 이 앱이 하는 일

thomas-shorts는 「Thomas의 AI 활용법」 운영자가 직접 만든 카드뉴스와 짧은 영상을 운영자 본인의 YouTube 채널(@th0m4s_ai)과 Instagram 계정(@th0m4s_ai)에 올리는 데에만 쓰는 내부 도구입니다. 다른 사람이 이 앱에 로그인하거나 사용하는 기능은 없습니다.

2. 이용하는 정보

  • 운영자 본인 계정의 OAuth 인증 토큰 (YouTube 업로드 권한, Instagram 게시 권한)
  • 업로드에 필요한 게시물 정보 (운영자가 만든 이미지·영상·제목·설명)

시청자나 다른 사용자의 개인정보는 수집하지 않습니다.

3. 보관과 공유

인증 토큰은 운영자의 비공개 서버에 운영자만 읽을 수 있는 권한으로 보관하며, 제3자에게 제공하거나 판매하지 않습니다. 게시물 이미지는 Instagram 게시를 위해 이 사이트(GitHub Pages)에 공개적으로 올라갈 수 있습니다.

4. YouTube API 서비스

이 앱은 YouTube API 서비스를 사용합니다. 이 앱을 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 정보 처리에는 Google 개인정보처리방침이 적용됩니다.

5. 접근 권한 철회

Google 계정의 서드파티 앱 접근 관리 페이지와 Instagram의 앱 및 웹사이트 설정에서 언제든 이 앱의 접근 권한을 철회할 수 있습니다. 철회하면 보관 중인 토큰은 더 이상 쓸 수 없으며 운영자가 삭제합니다.

6. 문의

이 방침에 관한 문의는 GitHub Issues로 남겨 주세요.

Privacy Policy

Effective: October 28, 2026 · App: thomas-shorts

thomas-shorts is an internal tool used only by the operator of "Thomas의 AI 활용법" to upload the operator's own card images and short videos to the operator's own YouTube channel (@th0m4s_ai) and Instagram account (@th0m4s_ai). No other user can sign in to or use this app.

Data used: OAuth tokens for the operator's own accounts (YouTube upload, Instagram content publishing) and the operator's own post content. No personal data of viewers or other users is collected.

Storage and sharing: Tokens are stored on the operator's private server with owner-only permissions and are never sold or shared with third parties. Post images may be publicly hosted on this site (GitHub Pages) for Instagram publishing.

YouTube API Services: This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is governed by the Google Privacy Policy.

Revoking access: Access can be revoked at any time via Google third-party access settings or Instagram's Apps and websites settings; stored tokens are then deleted.

Contact: GitHub Issues.
